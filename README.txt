ЛР №1 — варіант 14. Етап 1: головний екран.

1. В Android Studio закрий запущений застосунок (Stop, якщо потрібно).
2. Розпакуй цей ZIP прямо в корінь свого проєкту SavingsCalculator,
   тобто у папку, де вже є каталоги app/ і gradle/.
3. Підтверди заміну файлів MainActivity.java та activity_main.xml.
   Інші файли будуть новими, існуючі strings.xml/themes.xml не чіпаємо.
4. Натисни Sync Project with Gradle Files, якщо IDE попросить,
   потім Run (зелений трикутник).

Очікуваний результат: темний головний екран, назва програми,
кнопки «Почати розрахунок» (тимчасово показує повідомлення) та «Вийти».
Це навмисно лише ЕТАП 1. Форми вводу та математичні розрахунки додаємо далі.

ВАЖЛИВО: package name має бути com.example.savingscalculator.
Якщо твій пакет відрізняється, потрібно змінити package у двох Java-файлах
та розмістити їх у каталозі, що відповідає твоєму пакету.
